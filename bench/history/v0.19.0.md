- ctfkit 0.19.0 · Python 3.13.7 · Windows
- 실행 시간은 5회 중앙값. 기기마다 다르므로 절댓값보다 비율을 본다.

- 이 파일은 `python bench/run.py --write` 가 만든다. 직접 고치지 않는다.
