# ROADMAP

ctfkit 개발 계획. 각 단계는 **통과 조건(Gate)** 을 만족해야 다음 단계로 넘어간다.
> 원칙: 미완성인 큰 프로젝트보다, 완성된 중간 규모 프로젝트가 낫다.
> Gate를 통과하지 못하면 다음 버전으로 가지 않고 현재 버전을 마무리한다.

## 마일스톤

| 버전 | 주차 | 목표 | 통과 조건(Gate) |
| --- | --- | --- | --- |
| v0.1 기초 | 1~4 | `codec` 모듈 + CLI 기본 | base64 / hex / URL / ROT 인코딩·디코딩이 명령어로 동작 |
| v0.3 기반 | 5~7 | 테스트, CI, 린터, 플러그인 구조로 리팩터링 | CI 통과 + 테스트 커버리지 70% 이상 |
| v0.4 웹 | 8~9 | `web` send / repeat / fuzz + allowlist | 로컬 실습 서버에 파라미터 퍼징이 동작 |
| v0.5 깊이 | 10~11 | `crack` + `auto` | 비즈네르 암호문을 키 없이 자동 해독 |
| v0.7 확장 | 12 | `forensic` + `workspace` (여유가 있을 때) | 파일 속 숨은 파일 탐지가 동작 |
| v1.0 완성 | 13 | PyPI 배포 + 문서 사이트 + 발표 | 다른 PC에서 `pip install` 후 바로 사용 가능 |

## 구현 예정 (Planned / 백로그)

지금 당장 만들지 않지만 잊지 않기 위해 적어 두는 항목들.
각 항목은 GitHub 이슈로 등록하고, 착수할 때 브랜치를 판다.

### codec
- [ ] JWT 디코드 및 서명 없는 변조 (`none` 알고리즘 실습용)
- [ ] 진법 변환 (2/8/10/16진수 상호 변환)
- [ ] Base32 / Base58 지원

### crack
- [ ] 해시 사전 공격 (rockyou 등 워드리스트 기반)
- [ ] XOR 다중 바이트 키 추정

### web
- [ ] `web seq`: 쿠키/토큰을 이어받는 멀티스텝 요청 체인 (로그인 흐름)
- [ ] `web diff`: 두 응답의 차이 하이라이트
- [ ] 응답 이상치 자동 탐지 (상태코드·길이 기준)

### forensic
- [ ] 스테가노그래피 기초 (이미지 LSB 확인)
- [ ] 파일 시그니처(매직 바이트) 데이터베이스 확장

### 인프라
- [ ] PyPI 자동 배포 (릴리즈 태그 기준)
- [ ] MkDocs 문서 사이트 + GitHub Pages
- [ ] CI 매트릭스 (Windows/Linux × Python 3.11~3.13)
