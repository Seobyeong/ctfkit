# 벤치마크: ctfkit 은 AI 에이전트의 토큰과 시간을 얼마나 줄이는가

AI 에이전트(Claude Code 등)가 CTF 문제를 풀 때 드는 비용은 세 가지다.

1. **호출 수**: 명령을 한 번 실행할 때마다 모델이 결과를 읽고 다음 행동을 정한다. 왕복이 늘수록 느리고 비싸다.
2. **작성 토큰**: 에이전트가 직접 써야 하는 명령과 코드. 모델이 생성하는 쪽이라 읽는 것보다 느리고 비싸다.
3. **읽기 토큰**: 에이전트가 읽어야 하는 명령 결과.

이 벤치마크는 같은 과제를 두 방법으로 풀어 위 값을 비교한다.

| 방법 | 내용 |
| --- | --- |
| 표준 라이브러리 | 파이썬 표준 라이브러리만으로 푸는 코드. 에이전트가 도구 없이 직접 짜는 경우를 가정한다 |
| ctfkit | `ctfkit -q <명령>` |

## 실행

```bash
python bench/run.py              # 표를 화면에 출력
python bench/run.py --write      # bench/RESULTS.md 와 bench/history/v<버전>.md 로 저장
python bench/run.py --repeat 5   # 실행 시간을 5번 재서 중앙값 사용
```

외부 패키지나 API 키가 필요 없다. 문제 파일은 실행할 때 임시 폴더에 만들고, 난수 시드를 고정해 매번 같은 문제가 나온다.
최신 결과는 [RESULTS.md](RESULTS.md), 버전별 기록은 [history/](history/) 에 있다.

## 과제 (13개)

과제 정의는 [tasks.py](tasks.py) 에 있다. 인코딩(한 겹·세 겹·다섯 겹), 고전 암호(시저·비즈네르·XOR),
큰 바이너리에서 플래그 찾기, JWT 변조, RSA(가까운 소인수·비너), 파일 뒤에 붙은 ZIP, 해시 사전 공격, cyclic 오프셋.

두 방법 모두 마지막 명령의 출력에 정답이 있어야 한다. `tests/test_bench.py` 가 이를 검사하므로,
어느 한쪽이 답을 못 내는 과제는 표에 올라가지 않는다.

## 측정 규칙

- **호출 수**: 실행한 명령의 개수.
- **작성 토큰**: 실행한 명령 문자열 전체. 여러 줄 코드는 heredoc 으로 넘긴다고 보고 코드 전체를 센다.
  앞 단계의 출력을 다음 명령에 붙여 넣는 경우 그 글자도 포함한다.
- **읽기 토큰**: 모든 단계의 stdout + stderr.
- **토큰 수**: UTF-8 바이트 수를 4로 나눈 추정값이다. 실제 토크나이저 결과와 다르다.
- **실행 시간**: 명령이 도는 시간만 잰다. 모델이 생각하고 글자를 생성하는 시간은 포함하지 않는다.

## 비교 대상을 어떻게 정했나

비교 대상을 일부러 비효율적으로 짜면 숫자는 좋아지지만 의미가 없다. 다음 기준을 지킨다.

- 표준 라이브러리 코드는 플래그 형식(`DH{...}`)을 알고 있다고 보고, 그것으로 걸러서 필요한 줄만 출력한다.
- 코드는 줄바꿈과 변수 이름을 줄여 짧게 쓴다.
- 풀이 방법을 미리 안다고 가정한다 (예: RSA 과제에서 처음부터 페르마 분해 코드를 쓴다).
  실제 에이전트는 방법을 찾는 데 왕복이 더 들기 때문에, 이 가정은 표준 라이브러리 쪽에 유리하다.
- 여러 겹 인코딩은 한 번에 한 겹씩 벗긴다고 가정한다. 안쪽 겹은 벗겨 봐야 알 수 있기 때문이다.

## 한계

- **표준 라이브러리만 비교한다.** pwntools, RsaCtfTool 같은 전문 도구가 설치돼 있으면 비교 대상의 코드가
  훨씬 짧아진다. 이 벤치마크는 "아무것도 설치되지 않은 환경" 을 기준으로 한다.
- **토큰은 추정값이다.** 한글이 많은 출력은 실제 토큰 수와 차이가 더 크다.
- **모델 비용을 직접 재지 않는다.** 실제 에이전트가 쓰는 토큰에는 시스템 프롬프트, 이전 대화, 생각하는 과정이
  포함된다. 호출 수가 줄면 이 비용도 함께 줄지만, 이 벤치마크의 숫자에는 들어 있지 않다.
  실제 에이전트로 잰 사례는 ROADMAP 의 v0.25 에서 따로 기록한다.
- **과제 선정이 결과를 좌우한다.** 과제 13개는 직접 고른 것이라 대표성이 완전하지 않다.
  ctfkit 이 불리한 과제(파일 뒤에 붙은 ZIP)도 빼지 않고 표에 남긴다.
